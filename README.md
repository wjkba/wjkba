# Hi, I'm wjkba

I design and build web apps end to end, from Figma to payments to the server they run on, and I prefer local-first and self-hosted whenever it fits.  
Currently deep in **Elixir**, **Phoenix LiveView** and **Ash**.

## Featured Projects

- [Boox Highlight Manager](https://github.com/wjkba/boox-highlight-manager)  
  Local-first PWA for Onyx Boox and KOReader highlights, with daily review, custom lists and backup export. Everything lives in the browser in **IndexedDB**, no account, no server.

- [Logostworek](https://logostworek.pl/)  
  Designed and built a store for a kids' speech therapy game, with a fully custom **Stripe** payment flow, transactional emails and limited drops with stock holds for concurrent buyers.

- [Letterboxd Review Reader](https://github.com/wjkba/letterboxd-review-reader)  
  Self-hosted e-ink reader for long-form Letterboxd reviews. Background jobs scrape reviews with live progress into **SQLite** via **Drizzle**, served by **TanStack Start** over **Tailscale**.

- [rym-charts](https://github.com/wjkba/rym-charts)  
  RateYourMusic chart tracker that sidesteps Cloudflare by importing CSV exports instead of scraping. Server-rendered with **Bun**, **Hono** and **HTMX**, no build step, parser fully unit-tested.

- [Lumina](https://github.com/AI-LAB-AGH/OpenAI-Hackathon)  
  Built for the **OpenAI Hackathon**: an orchestrator agent routing to quiz, Q&A and summary agents over vector search of your notes, with voice chat and streamed responses.

- [FKN AGH Science Club Website](https://fkn.agh.edu.pl/)  
  Designed and built the film club's review site with **Astro**: Markdown reviews in type-safe content collections validated by **Zod**, static pages with React islands only where needed.
